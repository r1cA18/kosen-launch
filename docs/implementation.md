# 初期実装の仕様と判断

2026年11月6日に初期化と設計を保存してから実装を開始した。全体構想は[プロダクト設計](product.md)と[連携設計](architecture.md)に残し、この文書では実装済みの範囲を定義する。

## 技術と責務

Bun・TypeScript・Hono・SQLite・Zod・MCP TypeScript SDKを使う。Hono JSXのサーバー描画で編集プレビューと公開ページの部品を共有する。任意のHTMLやJavaScriptをアップロードして実行する機能は持たない。

UIの操作部品はdaisyUI 5とTailwind CSS 4。公開画面の配色と寸法と書体はr1ca18.devを基準にする。CSSとローカルフォントをビルド時に生成する。参照元と再利用の範囲は[画面とデザインの方針](design.md)に記録する。

制作資料の読解と作品内容の生成は外部のコーディングエージェントが行う。共通Schemaと文章ルールを取得してMCPから下書きを送信する。Webは本人による編集と公開と共有を担当する。選択した作品と保存した機会からの準備案にClaude APIを使う。交流と機会の詳細は[追加実装](social-and-opportunities.md)を参照。

## 認証と所有権

パスワードはArgon2idで保存する。セッションはHttpOnly Cookieで7日間有効。HTTPSの公開先ではSecure属性を付ける。書き込み要求はOriginを検証する。認証APIの試行制限はプロセス内で管理する。

連携トークンは32バイトの乱数から生成しハッシュだけをDBへ保存する。7日間有効で本人が失効できる。Bearer認証は本人の作品取得・下書き作成・画像送信・更新案・レビューURLの取得に限定する。公開と直接上書きとアカウント管理にはWebセッションが必要。

作品と画像の所有者を確認する。公開画像は公開版から参照されている場合だけ匿名で取得できる。学校の登録情報と根拠のメモとsource_keyと認証情報は公開データへ出さない。本文に書かれた情報は公開されるためプレビューで確認する。

## 作品の版と公開

`source_key`は利用者ごとに一意で同じ作品の作成リトライを重複にしない。編集ごとに新しい版を保存する。編集時の`base_revision`が現在と異なれば409を返す。

MCPからの再編集は更新案として保存する。本人が採用する際にも元の版が一致するか確認する。公開処理は選んだ版をコピーしたスナップショットを保存するため下書きの編集で公開内容は変わらない。公開停止で公開ページと匿名での画像取得を停止する。

## 追加実装と次の作業

実資料3件を使うローカルのMCP取り込みから公開と交流までの検証を完了した。[実資料の検証記録](real-material-validation.md)を参照。担当判定Skillと非公開のassessmentを追加した。作品への質問と返信と通知と役割付きの誘いを実装した。

Claude APIの接続処理と失敗時の挙動とキャッシュと利用上限を実装した。実キーがないため実APIの生成品質は未検証。現在は本人が機会URLと条件を保存する。イベント情報の自動収集とAI人物マッチングは残る。

外部公開する段階で認証のメール確認と復旧手段とアカウント削除と永続ボリュームとバックアップを整える。SQLiteの追加テーブルと生成元スナップショット列は存在確認付きで更新する。一般的なMigration管理とバックアップ復元の運用は未整備。

## 編集コンソール 2026年11月8日

本人の指定によりr1ca18.devの公開ページと同じ見た目のまま表記を直せる画面を追加した。

- `/works/:id/console`: 公開ページの文字組みで本文をクリックして直接編集する。保存は既存の`/works/:id/save`と`base_revision`の競合検出を使い公開版は変えない
- 右側の表記チェック: 全角英数字・半角カナ・技術名の大文字小文字・連続空白・日本語と英数字の間の空白・句読点を検出し修正案を示す。です・ます調でない文末は指摘のみ
- 修正の適用は保存済みの版に対して行う。未保存の編集がある間は適用ボタンを無効にする
- `/works/text`: 全作品の下書きを対象に文字列を一括置換する。適用前に作品ごとの差分を表示し、選んだ作品だけ更新する。読み込み後に更新された作品は変更せず件数を返す
- 判定と置換は`src/console.ts`、画面は`src/console-ui.tsx`、クライアント処理は`public/console.js`
- `sources`と`assessment`は置換の対象にしない

テストは`tests/console.test.ts`。ブラウザーでは一時DBと架空データで編集・保存・一括修正・一括置換と390px幅の表示を確認した。
