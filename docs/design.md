## 公開画面

本人の名前と公開IDの下へ作品一覧を置く。年とタグのフィルターを持ち、デスクトップでは3列を基本にする。画像の全体が見えるようサムネイルは`object-fit: contain`を使う。画像がない作品は種類を示す空の状態にする。

白い背景と小さなドットと半透明の作品カードを組み合わせる。公開カードは大きい作品名と短い概要と役割を表示する。本文は読むための幅へ制限し、担当と工夫と結果を順に置く。

今回のドットと透け感は新規のCSSによる表現。参考サイトのWebGLとMeniscusと粒子アニメーションをコピーしたものではなく同じ光学効果を再現したとは扱わない。

## ダッシュボード

Hono JSXのHTMLにdaisyUI 5とTailwind CSS 4を組み合わせる。Button・Input・Textarea・Select・Checkbox・Menu・Badge・Alert・Cardを利用する。`kosen`テーマへ共通の配色と角丸を設定する。既存のセッションとフォーム送信とMCPを保持する。

操作画面は白を基調にした静かな背景と左ナビゲーションを使う。モバイルでは上部ナビゲーションへ変える。公開用の飾りを入力欄へ広げず、入力内容とプレビューの区別を優先する。フォーカス表示とエラー表示と空の状態を維持する。

## ビルドと依存関係

`src/styles/app.css`がCSSの正本。`scripts/assets.ts`がTailwindとdaisyUIをコンパイルし、Fontsourceのフォントとライセンスを`public/`へ配置する。`public/style.css`とフォントは生成物としてGitから除外する。

`bun run dev`はCSSとサーバーを監視する。`bun run build`はCSSとフォントの生成を含む。CDNへの実行時アクセスは不要。書体は必要なUnicode範囲をブラウザーが読み込む。

daisyUIが使うutilitiesレイヤーに合わせて製品の調整もutilitiesレイヤーへ置く。部品の色と寸法を変更する際は専用CSSを重ねる前に共通テーマを確認する。

## 再利用と大会条件

本人の要望は可能な範囲の流用。参加者ガイドには既存コードの利用不可の記載があるため、今回取り込んだのはデザインの仕様と汎用ライブラリと配布フォント。r1ca18.devのアプリケーションコードとプロフィールと実績本文と画像はコピーしていない。汎用依存関係を自分たちが作った機能として紹介しない。

提出時に既存コードの流用を広げる場合は、その範囲が大会で認められるかを別途確認する。現在の実装は既存サイトのコードを取り込まなくても起動できる。

## UI編集コンソール

2026年11月8日に追加。r1ca18.devのローカル編集Studioと同じく、画面に表示された文言をその場で直し、変更をリポジトリへ取り込む。

- `bun run dev:edit`で起動する。`UI_EDITOR=1`かつloopbackで待ち受ける場合だけ有効
- 右下の「UI編集」で編集モードにし、文言をクリックして直す。入力欄の説明文はパネルから直す
- 「ソースに反映」で`src/`の同じ文字列リテラルとJSXの文言を書き換え、Prettierで整形する。変更は`git diff`で確認する
- 同じ文言が複数箇所にある場合は場所を示し、「すべて変更」を押したときだけ変える
- 数値や入力データを含む動的な文字列と、部分一致は変更しない
- `{ } < > ' " ` \`と改行を含む変更は拒否する
- 本番やloopback以外のHostでは編集用のスクリプトもAPIも配信しない

実装は`src/ui-editor.ts`と`public/ui-editor.js`と`public/ui-editor.css`。ファイルの書き込みは応答の後に行い、watchの再起動で応答が失われないようにしている。

## リキッドグラスとトップページ

2026年11月8日に追加。r1ca18.devと同じ素材感を新規のコードで再現した。

- `public/app.js`が32px間隔の点を全画面のcanvasに描画する。点はゆっくり明滅し、ポインターから離れる。視差効果を減らす設定では静止する
- カード・メニュー・投稿欄・補助ボタンは、このcanvasをぼかす半透明の面にする。上端の光沢、ポインター位置のハイライト、縁の光、ホバー時の虹色の屈折を重ねる
- JavaScriptが無い場合はCSSのドット背景と半透明の面になる
- 未ログインの`/`はdaisyUIの`hero`で作ったトップページ。説明は1文とし、手順をDraft・Review・Connectの3枚で示す
- ログインとアカウント作成はdaisyUIの`tabs`・`fieldset`・`validator`で作った中央のカード
