# Kosen Launch

高専での制作をポートフォリオと次の活動につなげるサービス。名称は仮称。
制作フォルダの読解と作品の文章作成は利用者のコーディングエージェントが担当し、このサービスで確認して公開する。

公開画面はr1ca18.devの配色と書体と作品の構成を参照する。ダッシュボードはdaisyUIとTailwind CSSを使う。

## 開発

Bun 1.4.2で動作確認。個人リポジトリとしてNixとdirenvの設定も管理する。

```sh
direnv allow
bun install --frozen-lockfile
bun run dev
```

Nixを使わない場合はBunを用意して後ろの2行を実行する。開発URLは`http://127.0.0.1:4177`。最初は利用者も作品も空の状態で起動する。

開発サーバーはCSSとフォントを生成してから起動しCSSの変更も監視する。スタイルの編集先は`src/styles/app.css`。フォントはローカル配信する。

標準設定で起動する場合は環境ファイル不要。設定変更時は`.env.example`を`.env`へコピーする。`APP_ORIGIN`はブラウザーから開くURLと一致させる。SQLiteは`.data/kosen-launch.sqlite`へ画像は`.data/assets`へ保存する。

## 最初の一件

1. Webでアカウントを作成
2. エージェント接続画面でトークンを発行
3. [接続手順](docs/agent-setup.md)に従いSkillとMCPを導入
4. コーディングエージェントへ制作フォルダを指定して下書き作成を依頼
5. Webの作品一覧で担当と内容を確認して必要な箇所を編集
6. 公開前の確認画面から公開

公開URLは`/u/{公開ID}`。作品の年とタグで絞り込める。「ホームにも共有する」を選んだ作品はフィードに掲載される。

## 実装済み

- アカウント登録とログインとログアウト
- 期限付き連携トークンの発行と失効
- Skill配布と7種類のstdio MCPツール
- 作品下書きと画像の送信と共通UIでのプレビュー
- 手動編集とエージェント更新案の採用・見送り
- 確認した版の公開と公開停止
- 公開ポートフォリオと年・タグによる絞り込み
- ホームへの任意共有と「気になる」のリアクション
- 資料からの担当判定と非公開の根拠・未確認事項
- 作品への質問と作者の返信と通知
- イベントと双方の役割を添えた誘いと受け入れ後の連絡先共有
- 質問の削除・通報と利用者のブロック
- 機会URLの保存と参加候補・応募済み・参加済み・見送りの管理
- Claude APIによる選択した作品からの準備案と利用量記録

Claude APIは`ANTHROPIC_API_KEY`を実行時に渡すと有効になる。キーはリポジトリに保存しない。`ANTHROPIC_MODEL`は省略時に`claude-sonnet-4-6`を使用する。現環境ではキー未設定のため実APIの生成品質は未検証。接続処理と失敗・再試行・上限は代替応答でテストした。

イベントの自動収集とAIによる人物マッチングは未実装。現在は作品のタグから外部検索し候補を保存する。共有作品から本人が役割を添えて相手を誘う。X連携と投稿文・スライド・動画生成も未実装。初期版はローカル開発用でメール確認やパスワード再設定や運用用のバックアップは含まない。

## 検証

```sh
bun run check
bun run format:check
bun test
bun run build
```

ビルド後はプロジェクトのルートから`bun run start`で起動する。配布時には`dist/`だけでなく`public/`と`skills/`も必要。
