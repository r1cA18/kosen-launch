# Kosen Launch

このプロジェクトは、授業や趣味で制作している高専生の「やったことが外に伝わらず、次の活動に誘われにくい」課題を、手元の制作資料から根拠付きの作品ページとイベントや仲間への誘いへ変えるWebサービスです。

Built with Claude Japan 2026（2026年11月6日〜8日）の期間中に、このリポジトリで新規に作りました。既存のコードは使っていません。依存するのはnpmの汎用ライブラリ（Hono、Zod、daisyUI、MCP SDK、Meniscusなど）だけです。

## 使い方の流れ

1. ClaudeにSkillとMCPを入れる（claude.ai・Claude Desktopはカスタムコネクタ、Claude Codeは`claude mcp add --transport http`）
2. 制作フォルダを渡すと、Claudeが分担表・個人報告・Git履歴を照合し、班全体の成果と本人の担当を分けた下書きを送る
3. Webで根拠と確認事項を見ながら、ページの見た目のまま直して公開する
4. 作品と関心に合うイベントが毎日自動で届く。保存すると準備案ができ、同じイベントを検討中の人を役割付きで誘える
5. 届いた誘いや参加希望をInboxで受け入れ、連絡先を共有する

## Claudeを使っている場所

| 場所         | 使い方                                                                                                     |
| ------------ | ---------------------------------------------------------------------------------------------------------- |
| 作品の下書き | 配布Skill＋MCP（stdio／リモートMCP＋OAuth 2.1）で、利用者のClaudeが資料を調べて下書きと更新案を送る        |
| イベント探索 | サーバーのClaude API（`claude-sonnet-5-5`）がweb searchで探し、検索結果に出たURLだけを採用する。1日1回自動 |
| 準備案       | 選んだ作品と保存したイベントから、担える役割・題材・確認事項・次の作業を構造化出力で作る                   |

## 既存サービスとの違い

| サービス   | 違い                                                                 |
| ---------- | -------------------------------------------------------------------- |
| note・Zenn | 本人が全部書く。班の中での担当の根拠は残らず、イベントにつながらない |
| LAPRAS     | 公開活動から作るため、授業や班の資料は読めない                       |
| ProtoPedia | 作品紹介が中心で、参加の場や仲間にはつながらない                     |
| connpass   | 自分の作品に合うかや、担える役割は分からない                         |

Kosen Launchは、班の中で本人が担った部分を根拠付きで示し、それを根拠に次の参加と仲間につなげます。

## Skillが品質を決めている根拠

同じ依頼文と同じ授業資料3件で、独立したClaude Codeに下書きを作らせて比べました（[記録](docs/real-material-validation.md)）。

- v1：公開欄に「本人が記入してください」が混ざる、ローカルパスから本人を推測する、などの問題
- v2（Skill改善後）：確認依頼は非公開の確認事項に移り、本人の特定は記名とGit作者だけで行う。担当を断定できない作品は「確認中」と書く

## 開発

Bun 1.4.2で動作確認。個人リポジトリとしてNixとdirenvの設定も管理する。

```sh
direnv allow
bun install --frozen-lockfile
bun run dev
```

画面の文言を直すときは`bun run dev:edit`で起動し、右下の「UI編集」から編集する。反映すると`src/`が書き換わる。詳細は[画面とデザインの方針](docs/design.md#ui編集コンソール)。

Nixを使わない場合はBunを用意して後ろの2行を実行する。開発URLは`http://127.0.0.1:4177`。最初は利用者も作品も空の状態で起動する。

開発サーバーはCSSとフォントを生成してから起動しCSSの変更も監視する。スタイルの編集先は`src/styles/app.css`。フォントはローカル配信する。

標準設定で起動する場合は環境ファイル不要。設定変更時は`.env.example`を`.env`へコピーする。`APP_ORIGIN`はブラウザーから開くURLと一致させる。SQLiteは`.data/kosen-launch.sqlite`へ画像は`.data/assets`へ保存する。

## 最初の一件

1. Webでアカウントを作成
2. 設定のAgentタブで接続方法を選ぶ
3. [接続手順](docs/agent-setup.md)に従いMCPとSkillを導入
   - claude.aiとClaude Desktop：カスタムコネクタに`<APP_ORIGIN>/mcp`を追加してOAuthで許可し、Skillのzipをアップロード
   - Claude Code：`claude mcp add --transport http kosen-launch <APP_ORIGIN>/mcp`で追加して`/mcp`から認証
   - その他のエージェント：連携トークンを発行してstdioアダプターを設定
4. エージェントへ制作資料を渡して下書き作成を依頼
5. Webの作品一覧で担当と内容を確認して必要な箇所を編集
6. 公開前の確認画面から公開

公開URLは`/u/{公開ID}`。作品の年とタグで絞り込める。「ホームにも共有する」を選んだ作品はフィードに掲載される。

## 実装済み

- アカウント登録とログインとログアウト
- 期限付き連携トークンの発行と失効
- リモートMCP（Streamable HTTPの`/mcp`とOAuth 2.1の認可サーバー）とstdio MCPの8種類のツール
- Skillのzip配布とMCP Skills拡張での配布
- 作品下書きと画像の送信と共通UIでのプレビュー
- 手動編集とエージェント更新案の採用・見送り
- 確認した版の公開と公開停止
- 公開ポートフォリオと年・タグによる絞り込み
- ホームへの任意共有と「気になる」のリアクション
- 資料からの担当判定と非公開の根拠・未確認事項
- 作品への質問と作者の返信と通知
- イベントと双方の役割を添えた誘いと受け入れ後の連絡先共有
- 質問の削除・通報と利用者のブロック
- 機会URLの保存と参加候補・応募済み・参加済み・見送りの管理
- Claude APIによる選択した作品からの準備案と利用量記録

Claude APIは`ANTHROPIC_API_KEY`を実行時に渡すと有効になる。キーはリポジトリに保存しない。`ANTHROPIC_MODEL`は省略時に`claude-sonnet-5-5`を使用する。現環境ではキー未設定のため実APIの生成品質は未検証。接続処理と失敗・再試行・上限は代替応答でテストした。

イベントの自動収集とAIによる人物マッチングは未実装。現在は作品のタグから外部検索し候補を保存する。共有作品から本人が役割を添えて相手を誘う。X連携と投稿文・スライド・動画生成も未実装。初期版はローカル開発用でメール確認やパスワード再設定や運用用のバックアップは含まない。

## 検証

```sh
bun run check
bun run format:check
bun run test
bun run build
```

ビルド後はプロジェクトのルートから`bun run start`で起動する。配布時には`dist/`だけでなく`public/`と`skills/`も必要。
